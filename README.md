# Modelo de Monitoreo de Fraude Interno

Prototipo académico desarrollado para el curso Seguridad y Auditoría de Sistemas.

## Características
- Datos sintéticos y seudonimizados.
- Motor de reglas de correlación.
- Dashboard de alertas.
- Revisión humana.
- Control de acceso por roles.
- Bitácora de auditoría.
- 28 pruebas automáticas.

## Instalación

Ejecutar:

INSTALAR_DEMO.bat

Luego:

INICIAR_DEMO.bat

Abrir en el navegador:

http://127.0.0.1:8000

## Pruebas

Ejecutar:

EJECUTAR_PRUEBAS.bat

Resultado esperado:

28 passed

## Alcance

Este proyecto es un MVP académico.

No utiliza datos reales ni está diseñado para producción.
